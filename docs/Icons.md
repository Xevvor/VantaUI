# Icons

Use `Icon` in tab options. Supported navigation names: `layout-dashboard`, `arrow-up-circle`, `footprints`, `git-branch`, `door-open`, `map-pin`, `settings`. Internal names: `resize`, `close`, `minus`, `down`, `chevron`. Unknown names fall back to chevron. Asset IDs are inherited from the original implementation and their visual accuracy and availability are not verified. Per-control icons are not implemented. The source includes attribution to the original icon mapping.
